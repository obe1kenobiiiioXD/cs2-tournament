# Обновление функций матчей

Для уже работающего проекта выполните `202611170001_match_integrity.sql` целиком в Supabase → SQL Editor. Скрипт обновляет только функции; турниры, команды и результаты сохраняются. Его можно запускать повторно.

Для новой базы используйте актуальный `supabase/schema.sql`: эти исправления уже включены.

После обновления:

- Матчи без пиков и банов открываются при пустом пуле или одной карте.
- Чтобы заменить команды в сыгранном матче, сначала сбросьте результат. Это также уберёт зависимые результаты следующих раундов.
- После создания плей-офф результаты и участников групп менять нельзя. Время и другие настройки матча остаются доступны.

Проверки: `npm ci && npm test` из корня репозитория. Тесты используют локальную PostgreSQL через PGlite и не обращаются к рабочей базе.
