# Organizm — платформа турниров по CS2

Сайт, где организаторы проводят турниры по Counter-Strike 2, а игроки находят их и регистрируются.

- **Вход через Steam** — без паролей и анкет; ник и аватар берутся из Steam.
- **Каталог турниров** с поиском и фильтрами: регистрация, идут, прошедшие, формат 5v5 / 2v2 / 1v1.
- **Создать турнир может любой** игрок. Турнир попадает в каталог после одобрения модератором.
- **Команды**: открытые или по коду приглашения, капитан, запасные, передача капитанства.
- **Три системы**: олимпийская, двойное выбывание (верхняя и нижняя сетки, гранд-финал), группы + плей-офф. Посев, автоматические проходы, переход победителя дальше.
- **Чек-ин** перед стартом: в сетку попадают только команды, подтвердившие участие.
- **Свободные агенты** и приглашения от капитанов; блок «Мои матчи» на главной с таймерами.
- **Рейтинг игроков**, статистика и история матчей в профиле.
- **Логотипы и обложки** можно загрузить файлом — картинка сжимается в браузере и хранится в Supabase Storage.
- **Пики и баны карт** капитанами прямо на сайте, Bo1 / Bo3 / Bo5, обновление в реальном времени.
- **Анонсы** турнира, профили игроков (FACEIT, Premier, контакты видны только сокомандникам и организатору).
- **Модерация**: очередь турниров, назначение администраторов, блокировка.

Подключение базы и входа через Steam — в [SETUP.md](SETUP.md). Пока сайт не подключён, он работает в демо-режиме.
